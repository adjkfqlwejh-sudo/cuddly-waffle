# ربات حرفه‌ای هواشناسی تلگرام — نسخه ۲

## امکانات
- کارت گرافیکی PNG برای گزارش کانال و نمایش وضعیت فعلی
- وضعیت فعلی، پیش‌بینی ۲۴ ساعته (۸ بازه سه‌ساعته) و پیش‌بینی ۵ روزه
- کیفیت هوا و شاخص AQI با OpenWeather Air Pollution API
- هشدار احتمال بارش، باد شدید، گرمای شدید و سرمای شدید
- انتخاب شهر از منوی ربات
- پشتیبانی از چند شهر و چند کانال
- پنل مدیریت و دستورات افزودن/حذف شهر و کانال و تغییر بازه ارسال
- ذخیره تنظیمات در SQLite

## متغیرهای Railway
ضروری:
- `BOT_TOKEN`: توکن جدید BotFather
- `OPENWEATHER_API_KEY`: کلید OpenWeather تازه
- `ADMIN_IDS`: شناسه عددی تلگرام مدیر/مدیران، با کاما برای چند نفر

پیشنهادی:
- `CHANNELS`: کانال‌ها با کاما، مثال `@channel1,@channel2`
- `CITY`: شهر اصلی، پیش‌فرض `Tehran`
- `COUNTRY`: کد کشور، پیش‌فرض `IR`
- `CITIES`: شهرهای اولیه با فرمت `City,CC;City2,CC`، پیش‌فرض از CITY/COUNTRY
- `TIMEZONE`: پیش‌فرض `Asia/Tehran`
- `POST_EVERY_HOURS`: فاصله انتشار اولیه، پیش‌فرض `5`
- `DB_PATH`: حتماً `/data/weather.db` وقتی Volume به `/data` وصل است
- `ALERT_RAIN_PERCENT`: آستانه احتمال باران، پیش‌فرض `65`
- `ALERT_WIND_KMH`: آستانه باد شدید، پیش‌فرض `50`
- `ALERT_COLD_C`: آستانه سرما، پیش‌فرض `0`
- `ALERT_HOT_C`: آستانه گرما، پیش‌فرض `40`
- `LOG_LEVEL`: پیش‌فرض `INFO`

## راه‌اندازی Railway
1. فایل‌های این پوشه را در ریشه همان GitHub repository آپلود/جایگزین کنید.
2. Railway همان GitHub service را به آخرین commit وصل و Deploy کند.
3. در Settings سرویس، یک Volume بسازید و Mount Path را `/data` قرار دهید.
4. در Variables مقادیر بالا را اضافه کنید. `ADMIN_IDS` باید شناسه عددی واقعی مدیر باشد.
5. مطمئن شوید ربات در هر کانال ادمین و مجاز به ارسال پیام است.
6. فقط یک replica اجرا کنید تا پیام‌های تکراری تولید نشود.

## دستورات مدیر در تلگرام
- `/start` نمایش منوی ربات
- `/health` بررسی فعال بودن
- `/postnow` ارسال فوری گزارش به همه کانال‌ها
- `/addcity London,GB` افزودن شهر
- `/delcity London` غیرفعال‌کردن شهر
- `/addchannel @channel` افزودن کانال
- `/delchannel @channel` غیرفعال‌کردن کانال
- `/setinterval 5` تنظیم فاصله ارسال بین ۱ تا ۲۴ ساعت

## نکات مهم
- کلیدها و توکن‌های افشاشده قبلی را باطل کنید و فقط کلیدهای جدید را در Railway وارد کنید.
- OpenWeather API ممکن است دسترسی به بعضی endpointها یا داده‌های Air Pollution را بر اساس پلن حساب محدود کند. اگر کیفیت هوا خطای API داد، بررسی کنید Air Pollution API برای کلید/حساب فعال باشد.
- OpenWeather 5-day forecast در این پیاده‌سازی داده‌های سه‌ساعته ارائه می‌کند؛ پیش‌بینی روزانه از آن خلاصه می‌شود و داده مستقل یک‌ساعته نیست.
- هشدارها بر اساس آستانه‌های ساده این برنامه و داده‌های پیش‌بینی ساخته می‌شوند؛ جایگزین هشدار رسمی هواشناسی نیستند.
- برای حفظ شهرها، کانال‌ها، زمان‌بندی و جلوگیری از تکرار هشدارها، Railway Volume با Mount Path برابر `/data` لازم است.
- اگر دکمه‌های رنگی در کلاینت تلگرام کاربر نمایش داده نشوند، ممکن است نسخه کلاینت یا Bot API پشتیبانی نکند؛ دکمه‌های Inline معمولی همچنان قابل استفاده‌اند.
