# ربات هواشناسی تلگرام

ربات پایتون برای نمایش وضعیت آب‌وهوای تهران، پیش‌بینی ۲۴ ساعت و ۵ روزه، و ارسال خودکار گزارش به کانال هر ۵ ساعت.

## نکات امنیتی مهم
- توکن ربات و کلید OpenWeather که قبلاً در چت فرستاده شده‌اند را باطل و جایگزین کنید.
- هیچ‌وقت فایل `.env` را برای کسی نفرستید یا در GitHub آپلود نکنید.
- ربات باید در کانال `@Stx_proxy_vpn` ادمین باشد و مجوز ارسال پیام داشته باشد.

## راه‌اندازی روی سرور Linux
1. Python 3.12 یا جدیدتر نصب کنید.
2. فایل‌ها را روی سرور کپی کنید.
3. محیط مجازی بسازید و وابستگی‌ها را نصب کنید:
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```
4. تنظیمات را کپی کنید:
   ```bash
   cp .env.example .env
   nano .env
   ```
   مقادیر `BOT_TOKEN` و `OPENWEATHER_API_KEY` را با کلیدهای تازه جایگزین کنید.
5. ربات را اجرا کنید:
   ```bash
   python bot.py
   ```

## دستورات
- `/start` یا `/weather` نمایش منوی ربات
- `/health` بررسی فعال بودن ربات
- `/postnow` ارسال فوری گزارش به کانال (در صورت تنظیم `ADMIN_IDS` فقط مدیران مجازند)

## امکانات
- گزارش فعلی: دما، دمای احساسی، کمینه/بیشینه، رطوبت، فشار، باد و ابرناکی
- پیش‌بینی ۲۴ ساعت (داده‌های ۳ ساعته OpenWeather)
- خلاصه پیش‌بینی ۵ روزه
- انتشار خودکار هر ۵ ساعت
- دکمه‌های شیشه‌ای آبی، سبز و قرمز در کلاینت‌های سازگار تلگرام

## نکته درباره برنامه زمان‌بندی
این نسخه پس از بالا آمدن برنامه، اولین گزارش زمان‌بندی‌شده را حدود ۱۰ ثانیه بعد ارسال می‌کند و سپس هر ۵ ساعت تکرار می‌کند. سرور باید همیشه روشن باشد. برای اجرای دائمی از systemd یا Docker استفاده کنید.
